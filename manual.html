SOP-ISOCALIB-1.4.3 Standard Operating Procedure · Zero-Server Geochemical Data Reduction

안정동위원소 정밀 데이터 리덕션 및 품질관리(QC) 실무 매뉴얼 Standard Operating Procedure for Stable Isotope Data Reduction & QC

본 매뉴얼은 GasBench II, Kiel IV, EA-IRMS, CRDS 등 안정동위원소 질량분석기에서 생성된 원시 데이터를 IsoCalib 플랫폼에서 정산할 때 필요한 전처리 옵션 선택, 엑셀 열 매핑, 시료 ID 네이밍 규칙, 원시 정밀도 경고 판독 및 트러블슈팅 전 과정을 상세히 규정합니다. This manual defines the complete workflow for reducing raw stable isotope data from GasBench II, Kiel IV, EA-IRMS, and CRDS systems using IsoCalib—covering preprocessing recipes, Excel column mapping, Sample ID naming conventions, Raw SD precision alerts, and troubleshooting.

02. 표준물질(Anchor & QC) 구성 및 원소함량(%C, %N) 설정 규칙 02. Reference Standards & Elemental %C/%N Setup

SECTION 01 UI

① 2점 검량 vs 3점 이상 다중 앵커 (+ Add Anchor): 기본적으로 앵커 01(저값)과 앵커 02(고값)의 2점 앵커가 제공됩니다. 측정 범위가 넓거나 비선형성이 우려될 때는 상단의 + 앵커 추가 버튼을 눌러 중간값 표준물질(예: NBS-19, IAEA-CO-8)을 추가하면 전체 표준물질에 대한 가중 선형 회귀(WLS)가 자동으로 확장됩니다.

② 표준물질 이름 매칭 원리: 표준물질 카드 우측 상단 입력칸의 이름(예: NBS-18)은 시퀀스 표의 Sample ID와 대소문자 및 하이픈(-)·공백을 무시하고 부분 일치로 매칭됩니다. 즉, NBS-18으로 설정하면 시퀀스의 NBS-18_1, nbs18-02, NBS18_End가 모두 자동으로 인식됩니다.

③ 표준물질 공인 원소 함량(%C Content, %N Content): Area / Blank 모드를 켜면 각 표준물질 카드 하단에 원소 함량 입력칸이 나타납니다. 표준물질의 질량과 피크 면적 비율로부터 기기의 응답 계수(Response Factor, $RF$ in Vs/mg)를 역산하여 미지 시료의 %C, %N, Atomic C/N을 계산합니다. 만약 표준물질 중 함량을 모르는 것이 있다면 해당 칸을 비워두면 입력된 표준물질들만 평균 내어 $RF$를 계산합니다.

④ 커스텀 프리셋 저장 (Reference Presets): 실험실 자체 내부 표준물질(In-house Standard, 예: KDO, YS-Carb) 세트를 입력한 뒤 이름을 적고 Save를 누르면 브라우저에 영구 저장되어 다음 접속 시 Load만으로 즉시 불러올 수 있습니다.

① 2-Point vs. Multi-Point Anchoring (+ Add Anchor): Two anchor cards (low and high endpoints) are loaded by default. Click + Add Anchor to insert intermediate reference materials (e.g., NBS-19, IAEA-CO-8); the York-Ludwig WLS solver dynamically scales to $N$ points.

② Case- & Symbol-Insensitive Matching: Standard names entered in Section 01 (e.g., NBS-18) match any run ID containing those alphanumeric characters (e.g., NBS-18_1, nbs18-02).

③ Certified Elemental Content (%C, %N): When Area mode is enabled, enter certified weight percentages for your standards. IsoCalib computes the instrument Response Factor ($RF$, Vs/mg) from standards with valid weights and certified percentages to quantify unknown sample %C, %N, and Atomic C/N.

④ Custom Presets: Save your laboratory's in-house standard suites using the Preset Bar for one-click retrieval across sessions.

03. 전처리 보정 옵션의 작동 순서와 선택 기준 03. 4-Stage Sequential Preprocessing Pipeline

MATHEMATICAL ORDER
[1단계] 캡슐 블랭크 차감 → [2단계] 피크 면적 선형성 정규화 → [3단계] 시퀀스 시간 표류 보정 → [4단계] 다중 앵커 WLS 스케일 교정 [Stage 1] Blank Subtraction → [Stage 2] Area Linearity → [Stage 3] Time Drift → [Stage 4] Multi-Point WLS Scale Anchoring

A. Area / Blank 4가지 모드 비교

  • Off: 피크 면적과 무게 열을 숨깁니다. 탄산염·물 분석의 표준 설정입니다.
  • Size Linearity: 빈 캡슐 오염은 무시할 수준이나, 시료 무게 편차로 인해 피크 크기(Area)가 커질수록 $\delta$값이 한쪽으로 기우는 이온원 비선형성만 보정합니다.
  • Blank Only: 극미량 시료에서 빈 주석 캡슐(BLANK)의 바탕값 기여분만 질량 보존 법칙으로 빼줍니다.
  • Blank + Size Linearity: EA-IRMS 유기물·퇴적물 분석의 권장 모드입니다. 블랭크 차감 후 면적 선형성을 보정하고 %C, %N 함량까지 산출합니다.
  • Off: Hides Weight and Area columns. Standard for carbonates and waters.
  • Size Linearity: Corrects ion-source linearity effects across varying peak areas without blank subtraction.
  • Blank Only: Applies mass-balance subtraction using average BLANK/BLK runs.
  • Blank + Size Linearity: Recommended for EA-IRMS; sequentially applies blank subtraction, area normalization, and %C/%N quantification.

B. Slope Method & Drift 선택 기준

  • Auto-Fit (Slope): 시퀀스 내에 Monitor 표준물질(예: USGS40)을 0.2mg, 0.5mg, 1.0mg처럼 무게를 다르게 여러 번 쟀을 때, 그 면적 대비 $\delta$ 기울기($k$)를 자동 회귀 산출합니다.
  • Manual Input (Slope): 크기별 표준물질을 넣지 않았을 때, 실험실에서 미리 확보한 선형성 계수($k$, ‰/Vs)를 직접 입력합니다. Figure 3·4에 빨간색 파선으로 기준 기울기가 표시됩니다.
  • Linear vs Anchor Bracketing (Drift): 분석 내내 기기 값이 한 방향으로 서서히 밀리면 Linear를, 중간에 기기 상태가 출렁이면 Anchor Bracketing(구간별 선형 보간)을 선택합니다.
  • Auto-Fit (Slope): Automatically regresses the $\delta$ vs. Area slope ($k$) from size-series runs of the selected Monitor standard.
  • Manual Input (Slope): Enter a pre-validated laboratory linearity factor ($k$, ‰/Vs); plotted as a red dashed line on Figures 3 & 4.
  • Linear vs. Bracketing (Drift): Use Linear for monotonic baseline drift, or Anchor Bracketing for piecewise spline interpolation between bracketing standards.

05. 시료 ID 필수 네이밍 규칙 및 자동 그룹화 알고리즘 05. Sample ID Naming & Auto-Grouping Rules

ID PARSER LOGIC

① 주석 캡슐 블랭크 인식 키워드: 빈 캡슐 바탕값 런은 시료명에 BLANK, BLK, 또는 TIN이 대소문자 무관하게 반드시 포함되어야 합니다 (예: Tin-Blank_01, BLK1). 블랭크 행은 검량선 피팅과 미지 시료 평균에서 자동 제외되며, 블랭크 차감 평균값 산출에만 사용됩니다.

② 연속 반복 시료 자동 그룹화 (Grouped Sample Summary): 엔진은 시료명 끝의 구분자(-, _, ., #, 공백) 뒤에 붙은 1자리 숫자(1~9, 01~09) 또는 알파벳 1글자(a~z)를 자동으로 떼어내어 기본 시료명(Base ID)을 추출합니다.

• Stalagmite-A_01, Stalagmite-A_02, Stalagmite-A_03 → Stalagmite-A (n = 3) 로 자동 통합
• Core-01_a, Core-01_b → Core-01 (n = 2) 로 자동 통합
* 주의: 같은 시료라도 중간에 표준물질(예: NBS-18)이나 다른 시료가 끼어 있으면 별개의 그룹으로 분리됩니다 (시퀀스 배치 순서 보존).

① Blank Detection Keywords: Blank runs must include BLANK, BLK, or TIN (case-insensitive) in their Sample ID (e.g., Tin-Blank_1, BLK_02) with weight set to 0.

② Adjacent Replicate Grouping: Trailing replicate suffixes (_1, -02, .a) are automatically stripped to aggregate consecutive unknown replicates into a single group mean ($\text{Mean} \pm 1\sigma$).

• Stalagmite-A_01, Stalagmite-A_02, Stalagmite-A_03 → Grouped as Stalagmite-A (n = 3)
* Note: Replicates separated by standards or other samples are intentionally kept as distinct sequence blocks.

06. 원시 1σ SD 정밀도 경고 & 앵커 보호 가드 운용법 06. Raw 1σ SD Precision Guard & Outlier Exclusion

QUALITY GUARD

① 원시 반복 정밀도 경고 (Raw SD Limit): 탄산염($\delta^{13}\text{C}, \delta^{18}\text{O}$) 분석에서는 기기 내부 펄스 반복 편차(Raw 1σ SD)가 0.100‰을 초과하면 반응 불완전이나 리크가 발생한 불량 데이터로 간주합니다. 데이터를 붙여넣는 즉시 임계치를 넘은 1σ SD 셀은 붉은색 배경으로 강조되며, 결과 표의 합성 불확도(± 1σ) 옆에 ▲ Raw 0.125 배지가 함께 표기됩니다.

② 앵커 표준물질 정밀도 경고 및 원클릭 자동 제외: 검량선 회귀의 기준이 되는 앵커 표준물질(예: NBS-18, IAEA-603) 자체의 Raw 1σ SD가 기준치를 초과하면, 검량선 기울기 전체가 왜곡됩니다. 이때 결과 배너 최상단에 긴급 경고창이 뜨며, 우측의 [불안정 앵커 자동 제외] 버튼을 누르면 해당 표준물질 런만 체크 해제되고 WLS 회귀선이 즉시 재계산됩니다.

③ 절대 행 삭제 대신 Use (✓) 체크 해제 사용: 이상치를 제거할 때 Delete Row로 행을 지워버리면 시퀀스 런 번호(#)와 시간 간격이 당겨져 시간 표류(Drift) 보정이 왜곡됩니다. 반드시 좌측의 Use (✓) 체크박스를 해제하여 시간축 위치는 보존한 채 계산에서만 제외하세요.

① Raw Repeatability Flagging (Raw SD Limit): For carbonates, internal pulse repeatability (Raw 1σ SD) exceeding 0.100‰ indicates incomplete acid digestion or vial leakage. Exceeding cells highlight in red immediately upon pasting, and result rows display a ▲ Raw 0.125 warning badge next to the combined uncertainty.

② Anchor Standard Precision Alert: If an active anchor standard exceeds the Raw SD Limit, a critical alert banner appears with a one-click Auto-Exclude Noisy Anchors button to protect the WLS slope (enforcing a minimum of 2 remaining active anchor runs).

③ Non-Destructive Outlier Toggle (Use ✓): Always uncheck Use (✓) rather than deleting rows so sequence run indices (#) and time-drift intervals remain intact.

07. 통계 지표(MSWD) 해독 및 QC PASS 판정 기준 07. Interpreting MSWD & QC Pass/Warning Criteria

STATISTICAL QC

• MSWD (Mean Square of Weighted Deviates, 축약 카이제곱): 다중 앵커 표준물질의 산포가 각 런의 측정 오차($1\sigma$) 범위 내에서 직선에 얼마나 잘 들어맞는지 나타냅니다. 1.0에 가까울수록 이상적(Optimal)이며, 2.5를 초과하면 High Scatter 경고가 표시됩니다. 이는 기기 드리프트 보정이 누락되었거나 표준물질 중 하나가 오염되었음을 의미합니다.

• 원소별 QC 허용 오차 기준 (정확도 Bias 및 반복 정밀도 1σ):

δ¹³C
± 0.08 ‰
δ¹⁸O
± 0.12 ‰
δ¹⁵N
± 0.15 ‰
δ³⁴S
± 0.20 ‰
δD (²H)
± 1.50 ‰

• MSWD (Reduced $\chi^2$): Values near 1.0 indicate optimal agreement between anchor residuals and analytical uncertainties. Values > 2.5 trigger a High Scatter flag, signaling unmodeled drift, size effects, or a compromised standard run.

08. 실전 트러블슈팅 FAQ (자주 겪는 오류 해결) 08. Practical Troubleshooting FAQ

DIAGNOSTICS

Q1. "At least 2 active anchor standard runs are required" 경고창이 뜨면서 계산이 안 됩니다.

원인 및 해결: Section 01에 입력한 표준물질 이름(예: NBS-18)과 시퀀스 표의 Sample ID 철자가 일치하지 않거나, 표준물질 런의 Use (✓) 체크가 모두 해제되어 활성화된 앵커가 2개 미만인 상태입니다. Section 01의 표준물질 이름을 시퀀스 표의 이름과 일치시키세요.

Solution: Ensure the standard names in Section 01 match the alphanumeric strings in your sequence Sample IDs and at least 2 anchor runs have Use (✓) checked.

Q2. EA-IRMS 모드에서 %C, %N, Atomic C/N 칸이 모두 - 로만 나옵니다.

원인 및 해결: 다음 3가지 중 하나가 빠진 경우입니다. ① 상단 Area / Blank가 Off로 되어 있음 → Blank + Size Linearity로 변경하세요. ② 입력 표의 Weight (mg) 열에 시료 무게가 입력되지 않았음. ③ Section 01 표준물질 카드 하단의 %C Content, %N Content 칸이 비어 있음.

Solution: Verify that (1) Area / Blank is enabled, (2) Weight (mg) values are populated in the sequence grid, and (3) certified %C/%N values are entered in Section 01 standard cards.

Q3. Grouped Sample Summary 탭에서 같은 시료 3개가 하나로 안 묶이고 따로 나옵니다.

원인 및 해결: 시료명 뒤에 두 자리 이상 숫자(예: Sample_10)가 붙었거나 구분자 없이 붙어 있으면(예: Sample1) 별도 시료로 인식합니다. 반복 측정 시료는 Sample_01, Sample_02, Sample_03 또는 Sample-a, Sample-b 형태로 표기해 주세요.

Solution: Use single-digit or single-letter replicate suffixes preceded by a delimiter (e.g., Sample_01, Sample_02, or Sample-a).

Q4. 탄산염 분석인데 δ¹⁸O 값이 VPDB가 아니라 VSMOW로 나옵니다.

원인 및 해결: Section 01 우측 툴바의 δ¹⁸O Scale 드롭다운이 VSMOW로 선택되어 있는지 확인하고 VPDB로 변경하면 표준물질 참값과 결과값이 즉시 VPDB 스케일로 환산됩니다.

Solution: Switch the δ¹⁸O Scale selector in Section 01 between VPDB and VSMOW; reference values convert automatically.
